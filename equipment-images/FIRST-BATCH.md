## What to supply manually

1. Open the linked Commons file description page and confirm the photographer, model evidence, license/version, and attribution instructions. Supply a saved description page or screenshot of that evidence along with the photograph if this environment remains unable to access it.
2. Download from the original source page. Do not substitute a dealer/Google copy or remove watermarks. Provide the original plus an optimized JPEG if you have made a derivative; otherwise the original can be optimized after upload. Do not relabel another file format with `.jpg`.
3. Confirm any representative-variant differences. D5H LGP, Scat Trak 1300D, Caterpillar 321D LCR, D3B, and JCB 530-70 are not verified company configurations. The F-550 and Tacoma match the supplied model/year claims but have unconfirmed body/trim configurations. None of the pictured units is established as company-owned.
4. **Keep the Volvo SD77 candidate on hold.** The inventory says SD77DX. The loader will retain its placeholder even if the assigned file is uploaded while `data-photo-hold="true"` remains. Confirm the variant difference before removing that hold.
5. Record the actual selected source, license, attribution, modification history, and model assessment in `photo-register.json`. Candidate fields remain separate from the selected/verified fields. No approval, license verification, or editing is implied by these prepared values.
6. The relevant cards already have conditional captions and credits matching these specific candidate sources. Upload only that source photo at the corresponding path. If you choose a different photo, update its `data-image-*` credit/caption attributes and register first, so a new image does not inherit someone else's credit.
7. When resizing, converting, or cropping, add a truthful `data-image-modifications` description to the card and record those changes. The expandable credit will display it. No file modifications have been made in this batch. CSS fitting does not crop the displayed image.
8. For CC BY-SA derivatives, keep the applicable BY-SA license on the modified photograph and retain attribution/change notices. This does not assert that the entire website is under that license. Confirm the source's actual requirements rather than relying on this candidate checklist.
9. The public-domain claim for the U.S. Army Scat Trak image is supplied as public domain **in the United States**; check the source's federal-work status and any relevant jurisdictional qualifications before use.
